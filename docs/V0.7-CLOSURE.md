## 1. 已交付能力

### 1.1 Python 3.10–3.15 现代语法（[SYNTAX-3.15.md](SYNTAX-3.15.md)）

- 结构化模式匹配 `match/case`：支持值模式、单例模式、或模式（`|`）、捕获/通配模式、序列模式（含 `*rest`）、映射模式、类模式（位置 `__match_args__` 与关键字属性）及 `if guard`。
- `async/await`、`async for`、`async with`、异步生成器及 `asyncio.run` 协同执行。
- PEP 695 泛型类型参数：`type Alias[T] = ...`、泛型类 `class C[T]:` 与泛型函数 `def f[T](...):`（调用点多态单态化特化）。
- `except*` 异常组语法、PEP 750 t-string（`TemplateStr`）、海象运算符 `:=`、`del`。

### 1.2 解释器服务（纯 Python 层）

- `eval` / `exec` / `compile`、`__import__`、`importlib.import_module`。
- `gc`（`collect`/`enable`/`disable`/`isenabled`/`get_count`）、`weakref`（`ref`）、`sys.getrefcount`、`sys.settrace`/`gettrace`、`sys.setprofile`/`getprofile`、`inspect.isfunction`。
- `threading.Thread` / `threading.Lock`（支持 `with lock:`）、`signal`（`SIGINT`/`SIGTERM`/`SIGABRT`/`signal`/`getsignal`/`raise_signal`）、`faulthandler`（`enable`/`disable`/`is_enabled`/`dump_traceback`）。

### 1.3 Vela 标准库（A3 清单）与 `unittest`

- `math`（硬件 SSE2 `sqrtsd` 及 `fabs`/`floor`/`ceil`/`trunc`/`gcd`/`lcm`/`factorial`/`isqrt`/`comb`/`perm`/`pi`/`e`/`tau`）。
- `json`（`dumps`/`loads`）、`random`（确定性 PRNG）、`collections`（`Counter`/`deque`）、`itertools`（`chain`/`repeat`/`islice`/`accumulate`）、`functools`（`reduce`/`lru_cache`/`cache`）、`dataclasses`（`@dataclass` 自动生成 `__init__`/`__eq__`）、`typing`（类型注解与 `cast`）、`re`（正则引擎 + `rt_str_cmp` 字符串字典序比较）、`datetime`（`date`/`datetime`/`timedelta` ISO 格式化）。
- `unittest`：可作为原生测试框架编译运行（`TestCase` 断言族与 `unittest.main()`）。
- 50 个纯 Python 包导入矩阵（25 个单文件 `.py` 模块 + 25 个含 `__init__.py` 的包目录）50/50 编译运行通过；缺失 C 扩展模块（`socket`/`sqlite3`/`ssl`）显式报 `ImportError`。

## 2. v0.7 基准性能实测与部署

- **重负载基准（`bench/run_bench.py --repeat 3`）**：
  - 对 CPython 3.13.3：`loop` **49.9x**（70.34 ms vs 3509.1 ms）、`collatz` **17.6x**、`primes` **12.7x**、`fib` **10.4x**，几何平均 **18.5x**。
