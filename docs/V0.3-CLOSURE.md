## 已交付

- 32 字节对象头、refcount、显式根栈、mark-sweep GC
- boxed int/float/bool/None/str/bytes
- list/tuple/dict/set：字面量、打印、下标、成员、append/extend/pop/count/index、keys/values/items、集合 `|`/`&`
- 字符串：拼接、比较、切片、len、upper/lower、startswith/endswith/find
- bigint：≤256 位字面量、打印、任意精度 `+ - *`、比较、len、int64 除数 `// %`、常量/常量局部变量除法折叠
- 异常：`raise/try/except/else/finally`、多 handler、类型匹配、跨帧展开、`assert`、完整调用栈帧（文件+函数+行号）、直接 cause
- 全局：模块常量、`global` 可变全局
- 闭包：嵌套函数、只读捕获、`nonlocal` 一元素 list cell
- 编译期 import：`import m`、`from m import f`、点路径、包目录、相对导入、模块常量属性
- boxed 调用约定、`OBJ` IR 类型
