# Vela v0.6 计划：类与函数语义

> 状态：已完成（2026-11-22），收口记录见 [V0.6-CLOSURE.md](V0.6-CLOSURE.md)
> 基线：v0.5.0 稳定版（243 tests、差分 11/11、800 语料、200 CPython 子集、list/dict/str ≥2x CPython）
> 目标版本：`0.6.0`

v0.6 完成 [V1.0-PLAN.md](V1.0-PLAN.md) 中的“类与函数语义”里程碑（原 v0.4 章节，在 v0.4–v0.5 完成运行时地基与精确 GC 后落地）：

## 1. 装饰器、闭包、`lambda` 与参数协议

- [x] `lambda` 表达式：提升为匿名函数对象，支持直接调用、作为参数传递、作为返回值传出。
- [x] 默认参数与关键字参数：支持位置默认参数、关键字参数重排、关键字默认回填。
- [x] `*args` 与 `**kwargs`：变长位置参数打包为 `list`、变长关键字参数打包为 `dict`，支持调用点 `*seq` 与 `**mapping` 解包。
- [x] 装饰器：支持单层/多层函数装饰器 `@dec`、带参装饰器工厂 `@dec(arg)`。
- [x] 词法闭包：支持嵌套函数捕获外层只读变量与 `nonlocal` 可变 cell 并作为函数对象返回（`rt_closure_new` 绑定环境列表，多次调用实例隔离）。

## 2. 推导式、解包、切片、f-string 与 `with`

- [x] f-string：支持 `f"...{expr}..."` 任意表达式插值与基础格式说明符。
- [x] 切片：支持 `str`、`list`、`tuple` 的负索引与 `[start:stop:step]` 步长切片（含 `[::-1]` 反转）。
- [x] 解包：支持多重赋值解包 `a, b = b, a`、嵌套解包 `a, (b, c) = ...`、星号解包 `a, *rest, b = ...` 及 `for k, v in ...` 循环目标解包。
- [x] 推导式：支持列表推导式 `[...]`、集合推导式 `{...}`、字典推导式 `{k: v ...}`、生成器表达式 `(...)`（含多重 `for` 与 `if` 过滤）。
- [x] `with` 语句：支持单/多上下文管理器 `with expr as var:`，自动调用 `__enter__` 并在 `finally` 中保证 `__exit__` 执行。

## 3. `class`、实例、MRO、`super()`、描述符、`property`、`__slots__`

- [x] `class` 定义与实例化：`__init__` 构造、实例属性读写 `self.x`、类属性访问与方法调用。
- [x] 继承与 MRO：单继承与多继承 C3 线性化 MRO、子类方法重写与多态分派、`isinstance()`。
- [x] `super()`：按当前类在 MRO 中的下一顺位解析父类方法（含 `super().__init__(...)` 与钻石继承协同 `super()`）。
- [x] `@property` 与描述符：支持 `@property` / `@x.setter` 属性读写拦截，以及实现了 `__get__`/`__set__` 的自定义描述符类。
- [x] `__slots__`：声明固定属性白名单，向未在继承链 `__slots__` 中声明的属性赋值时显式报错。

## 4. dunder 协议

- [x] 算术协议：`__add__`、`__sub__`、`__mul__`、`__floordiv__`、`__mod__`、`__neg__`。
- [x] 比较协议：`__eq__`、`__ne__`、`__lt__`、`__le__`、`__gt__`、`__ge__`。
- [x] 容器协议：`__len__`、`__getitem__`、`__setitem__`、`__contains__`。
- [x] 迭代、调用与字符串协议：`__iter__`/`__next__`（配合 `for x in obj`、`iter()`、`next()`）、`__call__`、`__str__`。

## 5. 生成器

- [x] `yield` 生成器函数：编译为状态机生成器对象，支持 `next(g)`、`for x in g:`、`list(g)`、`sum(g)`。
- [x] `yield from`：委托子生成器/可迭代对象逐项产出。
- [x] `send` / `throw` / `close`：支持 `v = (yield out)` 双向通信、`g.throw(...)` 注入异常（可在生成器内 `try/except` 捕获）与 `g.close()` 关闭（触发 `finally` 清理并阻止后续 `next/send`）。

## 6. 验收门槛（Gate）

- [x] `test_grammar`、`test_scope`、`test_funcattrs` 等纯 Python 语义测试集通过。
- [x] 全量 unittest（264 个）、差分 11/11、生成语料 800/800、CPython 子集 200/200 保持全绿。
