# Vela v0.10 收口总结（全面双语 i18n、`--set-lang` 持久化与中文运行时诊断）

> 收口日期：2026-11-27 · 版本：`0.10.0` · 对应计划：[V0.10-PLAN.md](V0.10-PLAN.md) / [V1.0-PLAN.md](V1.0-PLAN.md)

## 1. 交付项核对

1. **`--lang`（临时）与 `--set-lang`（永久默认）双层语言开关**（`vela/i18n.py`、`vela/cli.py`）：
   - `--lang zh|en` 仅对当次命令生效（`i18n.set_lang`），每次 `main()` 入口自动清理上一次进程内临时覆盖。
   - 新增 `--set-lang zh|en`（及 `--set-lang=zh|en`），将默认显示语言持久化写入 `~/.vela_lang`（可通过 `VELA_LANG_CONFIG` 覆盖路径），并输出中英确认提示。
   - 严格执行四级优先级：`--lang` > `VELA_LANG` 环境变量 > `--set-lang` 持久化文件 > 默认 `en`。
2. **消息 ID 注册表与全量编译期诊断双语化**（`vela/i18n.py`、`vela/errors.py`、`vela/cli.py`）：
   - `i18n.EN` 与 `i18n.ZH` 包含全部 CLI 状态（`build/run/check/bench`、`--stats`、`--emit-ir`、`--emit-asm`）、运行时错误（`rt.*`）、编译期/类型错误（`diag.*`）与特性模板（`feat.*`），键集合与 `{placeholder}` 占位符 100% 一致。
   - `VelaError` 同时支持 `key + **params` 与参数化模板自动匹配（`translate_diagnostic`），确保 `--lang en` 与 `v0.9.0` 输出逐字节一致，`--lang zh` 全量输出中文诊断。
3. **编译产物 `.exe` 运行时错误随编译期语言生成**（`vela/runtime.py`）：
   - `Runtime.__init__` 中的 15 类运行时错误全部接入 `i18n.t("rt.*")`。
   - `vela build --lang zh`（或在 `--set-lang zh` 默认中文下）编译出的独立 `.exe` 在发生除零、int64 溢出、负指数、`range()` 步长零等错误时输出中文 `Vela 运行时错误：...`。
4. **安装包、文档与残留扫描**（`installer/vela.iss`、`installer/ChineseSimplified.isl`、`README.md`、[PROFILE.md](PROFILE.md)、`tests/test_v010.py`）：
   - `installer/vela.iss` 集成 `ChineseSimplified.isl` 双语安装向导。
   - `README.md` 与 [PROFILE.md](PROFILE.md) 补充双语摘要、`--lang`/`--set-lang`/`VELA_LANG` 说明与统一术语表。
