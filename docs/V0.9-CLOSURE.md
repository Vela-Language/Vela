# Vela v0.9 收口总结（后端性能优化 P4–P7、`--emit-asm` 与 14 项全量基准）

> 收口日期：2026-11-27 · 版本：`0.9.0` · 对应计划：[V0.9-PLAN.md](V0.9-PLAN.md) / [V1.0-PLAN.md](V1.0-PLAN.md)

## 1. 交付项核对

1. **P4 寄存器分配与指令选择升级**（`vela/opt.py`、`vela/regalloc.py`、`vela/emit.py`、`vela/x64.py`）：
   - 实现 `coalesce_copies` 局部拷贝接合，消除算术/调用结果写入临时寄存器再 `mov` 到目标变量的冗余拷贝。
   - 实现 `find_imm_only_vregs` 与 `is_imm_operand` 32 位立即数直编（配合 `0x83` 8 位符号扩展短编码），将循环上限、步长、掩码与乘数直接编码进 x86-64 指令流，不占用通用寄存器。
   - 实现 `eliminate_box_unbox` 消除内联函数与方法边界上的 `rt_box_* -> rt_unbox_*` 及无逃逸 `rt_decref`。
2. **P5 基本块重排与跳转消减**（`vela/opt.py`、`vela/emit.py`）：
   - 实现 `thread_jumps` 跳转链折叠、常量 `br` 折叠与不可达死块剪枝（自动消除字面量步长下的 `for_bad_step`）。
   - 实现 `reorder_loop_exits` 将冷循环退出块移至循环回边之后，并在 `FuncEmitter` 中利用 `next_block_label` 自动反转 `jcc` 或省略落空 `jmp`；整数溢出检查改为单条不命中直通 `jo rt_overflow`。
3. **P6 循环优化**（`vela/opt.py`、`vela/inline.py`）：
   - 实现支配校验下的 `hoist_loop_invariants`（LICM），将循环内不变 `float`/64 位常量及纯计算（如 `strlen`）外提至 Preheader。
   - 实现 `fold_counting_loops` 归纳变量闭式归约、`if_convert_diamonds` 奇偶分支无分支化、`unroll_simple_loops` 4x 循环展开与 LCG 仿射四步复合归约，以及 `vela/inline.py` 自递归数值函数深度 3 展开。
4. **P7 常量整除与取模魔数乘法**（`vela/lower.py`、`vela/opt.py`、`vela/emit.py`、`vela/runtime.py`）：
   - 对正整数常量除数 $d \ge 2$ 采用无分支 64 位魔数乘法（$\lfloor a/d \rfloor = (((a \oplus s) \cdot M) \gg (64+k)) \oplus s$，$s = a \gg 63$），100% 精确覆盖全部正负 `int64` 的 Python 向下取整整除与取模。
   - 优化运行时 `rt_idiv` / `rt_imod`、`KEY_EQ` 与 `STR_EQ`（增加指针相等 O(1) 快路径与冷分支外置）。
5. **调试信息、异常栈寄存器恢复与 `--emit-asm`**（`vela/ir_dump.py`、`vela/cli.py`、`vela/runtime.py`）：
   - `vela build <file.vl> --emit-asm` 输出 `.asm` 汇编与符号偏移映射表（含函数/基本块 `.text` 偏移、寄存器分配表与机器码字节流）。
   - `rt_try_push` / `rt_raise` 扩展为 128 字节上下文槽，跨函数异常展开时完整恢复 `rbx, rsi, rdi, r12..r15`。
