## 阶段 1：运行时长除法（两个 bigint 变量）

### 问题

v0.3 只支持 int64 除数与常量折叠；两次“IR 长除法”尝试分别挂起/算错，已回退。

### 方案

在运行时用十进制数位数组做长除法，不依赖 IR 循环：

- 输入 a、b 的十进制数位（小端，ASCII）。
- 外层从被除数最高位到最低位：
  - 余数数组左移一位并追加当前位；
  - 用 0..9 试探商位：比较 `余数` 与 `b * digit`，选最大可行值；
  - 余数减去 `b * digit`。
- 商位数位写入结果对象；余数按需返回。
- 所有 buffer 用堆分配，长度按 `len(a)+len(b)` 计算。
- 先用合成 IR 探针验证 `20 位 / 19 位`、`30 位 / 10 位`、相等、整除、余数边界。

### 验收

- [x] `print(a // b, a % b)` 对非恒定变量给出与 CPython 一致的结果
- [x] 20/20 位、30/25 位函数参数除法与余数实测通过
- [x] 非负被除数/正除数校验，除零/负数显式报错
- 超时保护：测试 10 秒内完成
- 失败路径显式报错，不挂起

## 阶段 2：可提升 boxed int

### 问题

boxed int 目前是原生 int64；溢出直接报错，无法自动提升 bigint。

### 方案（候选，需先写 ADR）

A. **全 boxed int 对象化**：boxed 模式下 INT 值统一为 OBJ（int 或 bigint），运行时 `rt_num_*` 分派；溢出时把 int 提升为 bigint。语义最直接，性能代价最大。
B. **槽位联合**：INT 局部槽可存原生 int64 或 bigint 指针（tagged），表达式仍原生；溢出时写回 bigint 槽。静态类型需引入 union，改动面小于 A，但歧义多。

优先评估 A：实现简单、可验证；性能在阶段 5 单独处理。

- [x] 运行时 `rt_num_add/sub/mul`：int/int 溢出时提升 bigint（正负数路径已验证）
- [x] 运行时 `rt_num_cmp`：int/bigint 混合比较
- [x] `--boxed-dyn` 模式骨架（CLI/driver/analyzer/lowering 标志）
- [x] `--boxed-dyn` 下 INT 字面量/变量/`+ - *`/比较/print 走 `rt_num_*`（溢出提升已验证）
- [x] 动态模式的函数参数/返回值与负数一元运算
- [x] 动态模式的 `for range` 循环（range 参数降为原生 int64，循环变量装箱）
- [x] 动态模式 `while` 循环（条件经 rt_is_true）
- [x] 动态模式 `// %`（int/int、bigint/int）
- [x] 动态模式 list/dict 元素参与整数运算（box_scalar 直接复用 OBJ）
- [x] 动态/bigint `abs()` 与 `min/max`
- [x] bigint `str()`（任意长度十进制描述符）
- [x] 负数 bigint 加减（sub 复用 add + neg）

### 验收

- `x = 2**62; x = x * 4; print(x)` 输出 `18446744073709551616`
- 现有 176 测试全绿
- 溢出不再触发 `integer overflow`

## 阶段 3：运行时模块对象与 `sys.modules`

- [x] `sys.modules` 名称注册表：编译期收集导入名，成员判断与 len 可用
- [x] 统一 value 模块对象：`__module_new` 构建 list 容器，`m.CONST` 走 `__module_get`
- [x] `sys.modules[常量名]` 返回真实模块对象，并可继续取常量属性
- [x] 字符串列表 `strlist` 与模块字符串对象（独立 list + 下标访问）
- [ ] 模块函数值；`sys.modules` 作为整体 dict 的值仍为名称占位
- 函数值需要 code 对象（入口地址 + arity）与间接调用约定。
- `import` 编译为模块对象构造/注册；`sys.modules` 为真实 dict。
- 先支持常量与直接函数调用，再支持把函数作为值传递。

## 阶段 4：栈图与循环 GC

- [ ] 为每个函数生成调用帧 live-OBJ 位图，GC 从帧链精确扫描。
- [x] 保守式自动栈扫描：栈上等于存活对象指针的字视为根。
- [x] 容器子对象传递标记：list/tuple/set/dict 递归标记至不动点。
- [x] 合成探针验证仅由父容器引用的子对象在 GC 后仍可访问。
- [x] `rt_gc_collect_exact`：跳过保守栈扫描，配合传递标记回收不可达环；合成双列表环探针通过。
- 循环回收采用 mark-sweep + 终结器队列；明确 `__del__` 与 weakref 语义。
- 先做“精确根扫描”，再做循环终结器。

## 阶段 5：性能与 CPython 测试

- list/dict/str 微基准 ≥2x CPython
- 200 个 CPython 纯 Python 测试通过
- 若 boxed int 对象化导致回退，评估 tagged 快路径
