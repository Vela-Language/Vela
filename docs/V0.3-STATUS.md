# Vela v0.3 运行时地基：历史中间状态存档

> **历史存档提示**：本文档为 2026-11-21 v0.3 开发中途的交接快照，当时列出的未完成项已在 v0.3–v0.6 全部完成。**当前唯一能力表请查阅 [CAPABILITIES.md](CAPABILITIES.md)，v0.3 最终收口记录见 [V0.3-CLOSURE.md](V0.3-CLOSURE.md)**。

## 已实现（未提交）

- 32 字节对象头：`[0]` 类型、`[8]` refcount、`[16]` GC 标记、`[24]` GC 链表 next；payload `+32`。
- 分配/释放：`rt_alloc`（payload 大小 + 32）、`rt_free`（摘链 + HeapFree）。
- 引用计数：`rt_incref`/`rt_decref`/`rt_refcount`；单例（True/False/None）不参与回收。
- GC：live 计数、显式 root 栈（1024）、`rt_gc_collect` mark-sweep；单例从 GC 链摘除。
- boxed 标量：int/float/bool/None/str/bytes，`rt_typeof`、`rt_is_true`、动态 `rt_print_obj`。
- 容器：list/tuple/dict/set（固定容量：list 1024 余量、dict 256）；下标、append/extend/pop(index)/count/index、dict keys/values/items、成员 `in`、集合 `|`/`&`。
- 字符串：`+`、`==`、下标、切片、len、upper/lower、startswith/endswith、find。
- bigint：十进制字面量（≤256 位）解析与打印；语言层 `+ - *` 任意精度（20 位以上已验证），运行时数位实现；`// %` 支持任意精度被除数 + int64 除数（<1e18）；比较运算按符号/长度/数位实现；两个 bigint 常量相除在编译期折叠；常量局部变量的除法在编译期折叠；无法确定值的变量相除仍显式报错。
- 异常：`raise`、`try/except/else/finally`、多 handler、类型匹配与跨帧展开、`assert`；`finally` 在 `return` 路径执行。
- 全局：模块常量只读内联、`global` 可变全局（运行时全局槽）。
- 纯 Python 模块：编译期同目录 `.vl` 展开、函数前缀合并。
- boxed 调用约定：参数/返回值/局部变量装箱，`OBJ` IR 类型与合成 IR 验证。

## 未完成（v0.3 Gate 缺口）

- bigint 任意精度：>18 位十进制四则运算仍走 int64 快路径会显式失败；溢出自动提升未实现。
- 模块对象/闭包 cell：嵌套函数、`nonlocal`、闭包捕获未实现。
- 运行时 import：路径/包/相对导入/`sys.modules` 未实现；当前仅编译期展开。
- 异常 traceback 与`raise ... from` 显示直接 cause；多级异常链未实现。
- 容器容量固定，超过容量显式报错（list 1024、dict 256）。
- 编译期导入支持 `import m`、`from m import f`、点路径、包目录与相对导入；模块常量与函数属性（`m.CONST`/`m.f()`）编译期内联；运行时模块对象与 `sys.modules` 未实现。
- 嵌套函数与只读外层变量捕获原生运行；`nonlocal` 通过一元素 list cell 实现可变共享；模块对象未实现。
- 未捕获异常输出异常消息与完整调用栈帧（文件 + 函数名 + 行号）；`raise ... from` 显示直接 cause；多级异常链未实现。
- 500 行脚本 `tests/fixtures/long500.vl` 原生运行并与 CPython 输出一致。
- boxed 测试已强制 `--strict` 原生模式；容器打印、bigint 字面量、str 形参、`finally` 返回路径均已原生通过。

## 关键约束

- 默认 profile 仍只支持 int64/f64 静态路径；`--boxed` 是对象运行时唯一入口。
- 新增运行时函数必须遵守 Win64 ABI：不破坏 callee-saved；寄存器池已排除 `rsi`，运行时辅助函数仍不得依赖调用方保存 `rsi`。
- 新增容器/字符串函数后必须同时跑 152 个 unittest、11 个差分用例与 500 语料。
- 提交需用户逐次批准，当前所有 v0.3 改动仍未提交。
