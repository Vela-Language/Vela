# Vela v0.3 运行时地基：当前状态与交接

> 目标在 40 轮内无法完成。本文件固定已完成部分与下一步入口，避免后续从头摸索。

## 已完成（未提交）

- 32 字节对象头：`[0]` 类型、`[8]` refcount、`[16]` GC 标记、`[24]` 链表 next；payload `+32`。
- 分配/释放：`rt_alloc`（payload 大小，内部加 32）、`rt_free`（摘链 + HeapFree）。
- 引用计数：`rt_incref`/`rt_decref`/`rt_refcount`。
- GC：live 计数、显式根栈（1024）、`rt_gc_collect` mark-sweep、单例移出链表。
- boxed 值：int/float/bool；True/False 单例（不朽 refcount）；`rt_typeof`。
- 装箱算术：add/sub/mul/floordiv/mod；比较 eq/ne/lt/gt/le/ge 返回 boxed bool。
- 拆箱类型校验（int/float/bool），类型错误走 `rt_fail`。
- 动态打印：`rt_print_obj`（int/float）。
- `OBJ` IR 类型 + call/return ABI（合成 IR 验证）。
- 测试：80 个 unittest，含合成 IR 可执行探针；差分 11/11。

## 未完成

- analyzer/lower 不产生 `OBJ`；语言层仍只有 int64/f64 静态路径。
- bigint、字符串/容器对象、异常、纯 Python import。
- 自动根扫描（精确栈图）；当前根需手工 push/pop。

## 下一步（前端迁移）

1. `vela/analyze.py`：为 profile 增加 boxed 模式标记；先只允许“整数常量 + 返回”走 `OBJ`，其余保持静态。
2. `vela/lower.py`：在 boxed 模式下把 int 常量/返回值改发 `call rt_box_int`，函数 `ret_ty` 改 `OBJ`。
3. `vela/emit.py`：`OBJ` 已支持 GPR/call/ret，无需改。
4. 新增 `.vl` 端到端测试：box → unbox → print，保持 80 个测试与差分全绿。
5. 再扩参数与局部变量；每步只动一层。

## 关键约束

- 不得破坏现有静态路径；boxed 模式需可开关。
- 任何未验证的 lowering 改动不得合入。
- GC 根必须随 boxed 局部变量同步 push/pop，否则 collect 会误回收。
- 提交需用户明确批准；当前改动全部只在本地。
