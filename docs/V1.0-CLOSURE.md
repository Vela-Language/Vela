## 1. Vela v1.0.0 里程碑总览（v0.1 → v1.0.0）

Vela v1.0.0 实现了**不依赖 LLVM、不依赖 MSVC/外部链接器、不内嵌 `python315.dll`** 的纯 Python 3.15.2 语法与核心语义 AOT 原生编译器：

1. **全自研后端与 P1–P7 优化管线**（`v0.1–v0.2`、`v0.9`）：
   - 自有 x86-64 指令编码器与 PE32+ 可执行文件直出器；支持 `--emit-ir` 与 `--emit-asm`（输出 `.text` 偏移、寄存器分配表与机器码字节流）。
   - P1 常量折叠/代数化简/DCE、P2 函数全内联与自递归深度 3 展开、P3 叶子函数免帧与大栈帧探测、P4 局部拷贝接合/32 位立即数直编/内联边界装箱拆箱消除、P5 跳转链折叠/循环冷出口外置/落空跳转消除、P6 支配校验 LICM/归纳变量闭式归约/4x 循环展开/LCG 四步复合/奇偶无分支化、P7 无分支 64 位魔数乘法常量整除与取模。
2. **对象运行时、精确位图 GC 与大整数**（`v0.3–v0.5`）：
   - 32 字节引用计数对象头、48 字节小对象 O(1) 自由链表池、不朽单例（`True`/`False`/`None`/`code`）。
   - 每函数 32 字节 GC 帧记录与 safepoint 64 位 `live-OBJ` 位图精确扫描，配合 PEP 442 四阶段循环终结器（`__del__`、`weakref.ref`、`weakref.finalize`、`gc.collect()`）。
   - 任意精度 `bigint`（含运行时十进制长除法与 `--boxed-dyn` int64 溢出自动提升）、`str`/`bytes`/`list`/`tuple`/`set`/`dict`。
3. **面向对象、生成器、Python 3.15 现代语法与 A3 标准库**（`v0.6–v0.8`）：
   - `class`、多继承 C3 线性化 MRO、钻石继承协同 `super()`、`@property`、描述符、`__slots__`、全套 dunder 协议。
   - 生成器状态机协程（`yield`/`yield from`/`send`/`throw`/`close`）、推导式、星号解包、步长切片、f-string、`with`、词法闭包、装饰器、`*args`/`**kwargs`。
   - Python 3.10–3.15 现代语法：`match/case` 结构化模式匹配、`async/await`/`async for`/`async with`/异步生成器、PEP 695 泛型特化、`ExceptionGroup` 多分支 `except*`、PEP 750 t-string、`:=`、`del`。
   - 解释器服务与 A3 标准库：`eval/exec/compile`、`__import__/importlib`、`sys.getrefcount`/`settrace`/`setprofile`、`inspect`、`threading.Thread`/`Lock`、`signal`、`faulthandler`、`traceback`（含 16 层多级 `raise ... from` 异常链）、`math`、`json`、`random`、`collections`、`itertools`、`functools`、`dataclasses`、`typing`、`re`、`datetime`、`unittest` 原生测试框架。
4. **100% 中英双语（i18n）与 `--set-lang` 持久化设置**（`v0.10`）：
   - 支持 `--lang zh|en`（当次命令临时覆盖）与 `--set-lang zh|en`（持久化修改默认显示语言），100% 中英消息键覆盖全部 CLI、编译期诊断与编译产物 `.exe` 运行时错误；Inno Setup 安装包提供中英双语界面。

## 4. 已知差异摘要

详见 [KNOWN-DIFFERENCES.md](KNOWN-DIFFERENCES.md)：
- **无 C 扩展（`.pyd`）**：v1.0 不内嵌 CPython 运行时、不加载 `numpy`/`pygame`/`Dear PyGui`/`sqlite3` 等 C 扩展模块（留至 v2.0 C ABI 阶段）。
- **单变量静态类型**：每个变量在作用域内保持单一静态类型（`--boxed-dyn` 支持 `int64` 溢出自动转 `bigint`）。
