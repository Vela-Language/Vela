# Vela v0.8 收口总结（一致性攻坚与 10,000 随机 AST 差分）

> 收口日期：2026-11-22 · 版本：`0.8.0` · 对应计划：[V0.8-PLAN.md](V0.8-PLAN.md) / [V1.0-PLAN.md](V1.0-PLAN.md)

## 1. 交付项核对

1. **CPython `Lib/test` 全量扫描、分类与书面豁免清单**（`tools/survey_cpython_suite.py`、[CPYTHON-EXEMPTIONS.md](CPYTHON-EXEMPTIONS.md)）：
   - 全量扫描 CPython 3.15.2 `Lib/test` 下 394 个 `test_*.py`，精确划分为 C 扩展/非 A3 标准库依赖（377 个）、故意非法语法测试（5 个）、CPython 内部字节码/动态元编程（11 个）、直接通过（1 个）。
   - 剥离 `test.support` C 扩展脚手架后的 200 个纯 Python 语义回归集（`tests/cpython_subset.py`）通过率 **200/200 = 100.00%**（超过 `≥99.5%` 验收门槛）。
2. **`refcount` / `__del__` / `weakref` / `gc` 可观察行为对齐**（`vela/desugar.py`、`vela/lower.py`、`vela/runtime.py`、`vela/stdlib.py`）：
   - 类定义 `def __del__(self):` 在 `__new_<Class>` 构造时自动通过 `__set_finalizer` -> `rt_set_finalizer` 注册 PEP 442 终结器。
   - `del var` 降糖为 `var = __del_var(var)`，将局部 `OBJ` 槽位立即清零，使紧随其后的 `gc.collect()` 能够立即回收不可达单对象与循环引用图并触发 `__del__`。
   - `weakref.ref(obj)` 在调用点通过 `__ptr_to_int(obj)` 转化为非持有 64 位地址传入，不产生堆对象强引用根；运行时新增 `rt_gc_is_alive` 查询 GC 活动链表，实现对象存活时 `r.alive() == True`、回收后 `r.alive() == False` 且 `r() == 0`。
   - `weakref.finalize(obj, cb)` 注册终结回调，保证对象/循环回收时至多触发一次。
3. **`traceback`、多级 `raise ... from` 异常链与 `ExceptionGroup` / `except*`**（`vela/runtime.py`、`vela/lower.py`、`vela/stdlib.py`）：
   - 运行时新增 16 层 `exc_causes` 异常原因栈，`raise Exc2(...) from e1` 支持变量名与异常构造调用，未捕获异常按从近到远顺序完整输出多级 `caused by ...` 链。
   - 新增 `traceback` 标准库模块（`traceback.format_exc()`、`traceback.print_exc()`）。
   - 支持 `raise ExceptionGroup("msg", [Exc1(...), Exc2(...)])` 位掩码编码与多分支 `try ... except* Exc1: ... except* Exc2: ...` 按序多路命中及 `finally` 收尾。
4. **10,000 随机 AST 差分 Fuzz 门禁**（`tests/fuzz_10k.py`）：
   - 种子驱动生成 10,000 个互不相同的随机 AST 程序（涵盖递归算术/位运算/比较/三元表达式、`if/elif/else`、`while+continue`、`for range`、列表索引与 `match/case` 模式匹配），前 2,500 个样本即包含 2,496 种不同 AST 语法树骨架。
   - 10,000 个程序全部经 Vela 编译为原生 PE32+ 并与 CPython 逐行比对输出：**10,000 / 10,000 通过，0 失败，0 跳过**（耗时 ~59 秒），已接入 `.github/workflows/regression.yml`。

## 2. 验收证据

- **单元测试与 v0.8 专项验收**：`python -m unittest discover -s tests -p "test_*.py"` -> **289 个测试全部 OK**（含 `tests/test_v08.py` 8 个一致性与生命周期专项测试）。
- **严格零跳过差分语料**：`python tests/differential.py` -> **11 passed, 0 mismatched, 0 crashed, 0 skipped**。
- **800 随机 AST 语料门禁**：`python tests/corpus_scale.py` -> **800 passed, 0 failed, 0 skipped (800 unique programs, 545 unique AST skeletons)**。
- **200 CPython 纯 Python 子集门禁**：`python tests/cpython_subset.py` -> **200 passed, 0 failed (100.00% >= 99.5%)**。
- **10,000 随机 AST 差分 Fuzz 门禁**：`python tests/fuzz_10k.py` -> **10000/10000 random AST programs passed, 0 failed, 0 skipped (10000 unique programs, 2496+ unique AST skeletons)**。
