## 1. 已交付能力

### 1.1 装饰器、词法闭包、`lambda` 与参数协议

- `lambda` 表达式自动提升为匿名函数对象，支持直接调用、高阶传递与作为返回值传出。
- 支持位置默认参数、关键字参数重排、关键字默认回填、`*args` 列表打包与 `*seq` 调用解包、`**kwargs` 字典打包与 `**mapping` 调用解包。
- 支持单层/多层函数装饰器 `@dec` 与带参装饰器工厂 `@dec(arg)`。
- 新增 `rt_closure_new(addr, arity, env_list)`：将外层只读捕获变量与 `nonlocal` 可变 cell 列表绑定到 `code` 对象 `[code + 48]`，调用时由 `rt_code_call_argv` 自动拼接闭包环境，GC 遍历自动标记闭包环境列表。

### 1.2 推导式、解包、切片、f-string 与 `with`

- f-string：支持 `int`/`float`/`bool`/`str`/`None`/任意表达式插值与 `rt_float_to_str` 转换。
- 切片：支持 `str`、`list`、`tuple` 的负索引（`s[-1]`、`xs[-2]`）与 `[start:stop:step]` 任意步长切片（含 `[::-1]` 反转）。
- 解包：支持交换解包 `a, b = b, a`、嵌套解包 `a, (b, c) = ...`、星号扩展解包 `a, *mid, b = ...` 与 `for k, v in ...` 循环目标解包。
- 推导式：支持列表推导式、集合推导式、字典推导式与生成器表达式（含多重 `for` 与 `if` 过滤）。
- `with` 语句：支持上下文管理器 `__enter__` 返回值绑定并在 `try/finally`（含异常抛出路径）中保证 `__exit__` 执行。

### 1.3 `class`、实例、MRO、`super()`、描述符、`property`、`__slots__`

- `class` 构造与实例属性读写（`__attr_get`/`__attr_set` 支持任意标量与容器/对象属性），修复函数返回 `OBJ` 局部变量时的 `boxed_cleanup` 保活。
- 单继承与多继承 C3 线性化 MRO、子类方法重写、`isinstance()` 类型判定、钻石继承协同 `super()` 解析。
- 支持 `@property` / `@x.setter` 属性拦截与实现了 `__get__`/`__set__` 的自定义描述符类（通过全局对象槽跨实例共享描述符状态）。
- 支持 `__slots__` 属性白名单校验，向未声明属性赋值时显式报错。

### 1.4 dunder 协议与生成器

- dunder 算术（`__add__`/`__sub__`/`__mul__`/`__floordiv__`/`__mod__`/`__neg__`）、比较（`__eq__`/`__ne__`/`__lt__`/`__le__`/`__gt__`/`__ge__`）、容器（`__len__`/`__getitem__`/`__setitem__`/`__contains__`）、调用（`__call__`）、字符串化（`__str__`）与迭代协议（`__iter__`/`__next__` + `StopIteration`）。
- 生成器（`yield` / `yield from` / `send` / `throw` / `close`）：编译为状态机生成器类，支持 `for` 迭代、`list()`、`sum()`、`yield from` 子生成器委托、`v = yield out` 协程双向通信、`g.throw()` 注入异常（可在生成器内 `try/except` 捕获）以及 `g.close()` 触发 `finally` 清理。
