# Vela v0.9 计划：后端性能优化（P4–P7）、`--emit-asm`/调试回溯与全量基准更新

> 状态：已完成（见 [V0.9-CLOSURE.md](V0.9-CLOSURE.md)）
> 基线：v0.8.0 稳定版（289 tests、11 差分、800 随机 AST、200 CPython 子集、10,000 随机 AST Fuzz）
> 目标版本：`0.9.0`

v0.9 对齐 [V1.0-PLAN.md](V1.0-PLAN.md) §2“v0.9 性能与工程”里程碑，并全面更新与扩充 `rainMark` 基准画廊：

## 1. P4–P7 后端机器码优化

- [x] **P4 寄存器分配与指令选择升级**（`vela/opt.py`、`vela/regalloc.py`、`vela/emit.py`）：
  - 局部拷贝接合（Copy Coalescing）：消除 `bin/un/cmp/const/str/call %tmp, ...; mov %var, %tmp` 产生的临时寄存器与冗余 `mov`/`movsd`。
  - 32 位立即数指令直编（Immediate Folding）：单用途常量在 `add`/`sub`/`mul`/`and`/`or`/`xor`/`shl`/`shr`/`cmp`/`idiv_c`/`imod_c` 中直接编码为 x86-64 `ri` 立即数指令（含 `-128..127` 4 字节 `0x83` 短立即数编码），消除常量占用通用寄存器与循环内 `movabs`。
  - 跨内联调用装箱/拆箱消除（Box/Unbox Elimination）：消除内联函数与方法边界上的 `rt_box_* -> rt_unbox_*` 及无逃逸 `rt_decref`。
- [x] **P5 基本块重排与跳转消减**（`vela/opt.py`、`vela/emit.py`）：
  - 跳转链折叠（Jump Threading）与常量条件分支折叠：若 `jmp/br` 目标块仅含单条 `jmp L2`，直接改写目标为 `L2` 并清理不可达死块（如字面量步长下的 `for_bad_step`）。
  - 循环冷出口外置重排（`reorder_loop_exits`）与落空跳转消除（Fallthrough Jump Elimination）：在 `emit` 中根据下一物理块标签自动反转 `jcc` 条件或省去末尾冗余 `jmp`，并将整数溢出检查改为不命中直通 `jo rt_overflow`。
- [x] **P6 循环优化**（`vela/opt.py`、`vela/inline.py`）：
  - 循环不变量外提（LICM）：支配前驱校验后，将自然循环内不变的 `float`/64 位常量及纯计算（如 `strlen`）外提至 Preheader。
  - 归纳变量闭式折叠（`fold_counting_loops`）与奇偶钻石分支无分支化（`if_convert_diamonds`）。
  - 简单计数循环 4x 展开与 LCG 仿射四步复合归约（`unroll_simple_loops`）。
  - 自递归函数深度 3 展开（Self-Recursive Unrolling）：在 `vela/inline.py` 中对自递归数值函数进行深度 3 自内联展开，消除 >93% 的叶节点函数调用开销。
- [x] **P7 常量整除与取模魔数乘法**（`vela/opt.py`、`vela/lower.py`、`vela/emit.py`）：
  - 对编译期正整数常量除数 $d \ge 2$ 的 `//` 与 `%`（`idiv_c` / `imod_c`），采用无分支 64 位魔数乘法 $M = \lfloor 2^{64+k}/d \rfloor + 1$（`s = a >> 63; u = a ^ s; mul M; shr rdx, k; q = q_u ^ s`）内联计算，100% 精确覆盖全部正负 `int64` 的 Python 向下取整语义，彻底消除 `call rt_idiv`/`rt_imod` 与硬件 `idiv`。
  - 变量除数的运行时 `rt_idiv`/`rt_imod` 热路径零跳转化（冷分支外置）。

## 2. 调试信息、崩溃栈回溯与 `--emit-asm`

- [x] 新增 CLI `--emit-asm` 选项（`vela build <file.vl> --emit-asm`）与 `vela.ir_dump.dump_asm`：输出函数与基本块 `.text` 十六进制偏移、寄存器/栈槽分配表、机器码字节流与 IR 助记符对照清单。
- [x] 跨函数异常栈展开（`rt_try_push` / `rt_raise`）完整保存并恢复全部非易失寄存器（`rbx, rsi, rdi, r12..r15`），并在活跃性图（`_block_succs`）中精确建模异常边。
- [x] 本地 `dist` 构建、启动器与安装包脚本实机验证测试（`tests/test_v09.py`）。
