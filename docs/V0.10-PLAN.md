# Vela v0.10 计划：全面双语（i18n）、`--set-lang` 持久化语言与中文运行时诊断

> 状态：已完成（见 [V0.10-CLOSURE.md](V0.10-CLOSURE.md)）
> 基线：v0.9.0 稳定版（297 tests、11 差分、800 随机 AST、200 CPython 子集、10,000 随机 AST Fuzz、14 组 5 方基准）
> 目标版本：`0.10.0`

v0.10 对齐 [V1.0-PLAN.md](V1.0-PLAN.md) §2“v0.10 全面双语（i18n）”里程碑及用户新增 `--set-lang` 要求：

## 1. `--lang`（临时）与 `--set-lang`（永久默认）语言管理

- [x] `--lang zh|en` 保持为当次命令临时覆盖显示语言。
- [x] 新增 `--set-lang zh|en` 永久修改默认显示语言（持久化写入用户语言配置文件 `~/.vela_lang`，支持 `VELA_LANG_CONFIG` 环境变量指定路径，优先级：`--lang` > `VELA_LANG` > `--set-lang` 持久化配置 > 默认 `en`）。
- [x] 支持单独执行 `vela --set-lang zh|en` 或携带子命令 `vela --set-lang zh check ...`。

## 2. 消息 ID 注册表与编译器全量诊断双语化

- [x] `vela/i18n.py` 建立完整中英消息 ID 注册表（`EN` / `ZH` 键集合与占位符 100% 一致）与诊断参数化模板翻译器 `translate_diagnostic`。
- [x] 覆盖 `analyze.py`、`lower.py`、`desugar.py`、`imports.py`、`errors.py`、`cli.py` 全部用户可见文本（含 `vela build/run/check/bench` 状态、`--stats` 统计、`--emit-ir`/`--emit-asm` 提示、语法错误与全部类型/编译期错误）。
- [x] `--lang en` 下所有诊断与 CLI 输出与 `v0.9.0` 逐字节一致。

## 3. 运行时错误随编译期语言生成（`vela/runtime.py`）

- [x] `vela/runtime.py` 所有运行时诊断字符串（除零、int64 溢出、负指数、`range()` 零步长、内存不足、列表容量/空列表 `pop`、大整数超限/除法、代码对象元数、字典缺键、字符串越界、未捕获异常、GC 根栈溢出、拆箱类型不匹配）按编译期语言生成。
- [x] `vela build --lang zh`（或 `--set-lang zh` 默认中文下）编译出的 `.exe` 运行时错误输出为中文。

## 4. 安装包、文档、CI 键一致性与残留扫描

- [x] 安装包：`installer/vela.iss` 随包提供 `installer/ChineseSimplified.isl`，`setup.exe` 可选简体中文与英文界面。
- [x] 文档：更新 `README.md` 与 [PROFILE.md](PROFILE.md) 双语摘要及 `--lang` / `--set-lang` / `VELA_LANG` 语言开关说明，统一术语表。
- [x] 测试与门禁（`tests/test_v010.py`）：
  - `EN` / `ZH` 键集合与 `{placeholder}` 占位符 100% 一致性断言；
  - `--set-lang` 持久化与 `--lang` 临时覆盖优先级测试；
  - `--lang zh` 与 `--lang en` 覆盖每类编译期诊断与 CLI 状态快照测试；
  - `vela build --lang zh` 中文 `.exe` 运行时错误（除零/溢出/负指数/`range` 零步长）实机测试；
  - 用户可见中文表无裸英文诊断残留扫描测试。
