# Vela v0.7 计划：现代语法、解释器服务与标准库

> 状态：已完成（2026-11-22），收口记录见 [V0.7-CLOSURE.md](V0.7-CLOSURE.md)
> 基线：v0.6.0 稳定版（266 tests、差分 11/11、800 随机 AST 语料、200 CPython 子集、基准计时门禁 19.8x）
> 目标版本：`0.7.0`

v0.7 完成 [V1.0-PLAN.md](V1.0-PLAN.md) 中顺延合并的三大板块：现代语法（Python 3.10–3.15）、纯 Python 层解释器服务、以及 Vela 版 A3 标准库子集。

## 1. 现代语法（Python 3.10–3.15）

- [x] `async/await`、`async for`、`async with`、异步生成器及 `asyncio.run` 协同执行。
- [x] `match/case` 结构化模式匹配：值模式、单例模式、或模式（`|`）、捕获/通配模式、序列模式（含 `*rest`）、映射模式、类模式（位置与关键字属性）及 `if guard`。
- [x] `except*` 异常组语法、PEP 695 泛型类型参数（`type Alias[T] = ...`、`def f[T](...):` 调用点多态单态化特化、`class C[T]:`）、PEP 750 t-string（`TemplateStr` / `t"..."`）、海象运算符 `:=`、`del`。
- [x] CPython 3.15 语法逐项对照表（[SYNTAX-3.15.md](SYNTAX-3.15.md)）。
- **Gate**：`test_syntax`、`test_patma`、`test_type_params` 通过。

## 2. 解释器服务（纯 Python 层）

- [x] `eval` / `exec` / `compile`、`__import__`、`importlib.import_module` 子集。
- [x] 运行时 `gc`、循环终结器、引用计数原语（`rt_gc_collect` / `rt_set_finalizer` / `rt_refcount`）。
- [x] Python 层 `gc`、`weakref`、`sys.getrefcount` 标准模块封装与终结回调对齐。
- [x] `sys.settrace` / `sys.setprofile`、帧追踪回调、`inspect` 子集。
- [x] 线程与同步：`threading.Thread`、`threading.Lock`（支持 `with lock:`）、GIL 语义。
- [x] 信号与 `faulthandler`（Windows 控制台最小集：`signal.signal/getsignal/raise_signal`、`faulthandler.enable/disable/is_enabled/dump_traceback`）。
- **Gate**：依赖这些服务的纯 Python 测试 ≥90% 通过。

## 3. 标准库（Vela 实现 · A3 清单）

- [x] `math`：SSE2 `sqrt`/`fabs`/`floor`/`ceil`/`trunc` 及 `gcd`/`lcm`/`factorial`/`isqrt`/`comb`/`perm`/`pi`/`e`/`tau`。
- [x] `json`：`json.dumps` 与 `json.loads` 纯 Python 原生编译实现。
- [x] `random`：确定性种子 PRNG（`seed`/`randint`/`randrange`/`choice`/`random`）。
- [x] `collections` / `itertools` / `functools`：`Counter`、`deque`、`chain`、`repeat`、`islice`、`accumulate`、`reduce`、`lru_cache`/`cache`。
- [x] `dataclasses` / `typing`：`@dataclass` 自动生成 `__init__`/`__eq__`，`typing` 全套类型注解与 `cast`。
- [x] `re`：Vela 简化正则引擎（`search`/`match`/`findall_digits`/`sub`，支持 `^ $ . * + ? \d \w \s`）及 `rt_str_cmp` 字符串字典序比较。
- [x] `datetime`：`date`、`datetime`、`timedelta` 与 ISO 格式化。
- [x] `unittest`：可作为测试框架在 Vela 原生编译运行（`TestCase` 断言族与 `unittest.main()`）。
- [x] 第三方纯 Python 包导入矩阵 ≥50 个（支持单文件模块与含 `__init__.py` 的包目录）。
- **Gate**：A3 清单 100% 可用；缺失 C 扩展模块给出明确 `ImportError`；50 个纯 py 包导入成功。
