# Vela v0.4 收口记录

> 收口日期：2026-11-22
> 基线：209 个 unittest、差分 11/11、生成语料 500/500、boxed 全 `--strict`
> 本地编译器：`0.4.0-dev.30-local.1`

v0.4 按“当前绿色子集收口、剩余架构项记录例外”的方式关闭，处理方式与 v0.3 相同。

## 1. 已接受并完成

### 1.1 可提升 boxed int

- `rt_num_add/sub/mul/cmp/neg/abs`：int/int 溢出自动提升 bigint，支持正负数。
- `--boxed-dyn` 模式：INT 字面量/变量/`+ - * // %`/比较/print 统一走 OBJ。
- 超 int64 字面量直接构造 bigint，不再截断为 boxed int。
- 动态模式支持函数参数/返回值、`for range`、`while`、list/dict 元素、绝对值、min/max。
- 动态 `// %` 统一走 bigint 长除法，覆盖 int/int、bigint/int、bigint/bigint 与负数。
- 15 组 60–64 位、10 组 20–35 位随机运算差分与 CPython 一致。

### 1.2 bigint 运行时长除法

- lowering 生成十进制长除法 IR，q/rem 使用固定 loop-carried vreg。
- 逐位尝试 0..9 商位，支持任意 bigint 除数与四种符号组合的 Python floor 语义。
- 非负被除数、正除数校验；除零/非法符号显式报错。
- 20/20 位、30/25 位、30 组 20–40 位随机差分通过。

### 1.3 运行时模块对象与 `sys.modules`

- `import` 常量生成统一模块容器：`__module_new` 构建 list，`m.CONST` 走 `__module_get` 并按静态类型拆箱。
- 支持 int/str/bool/float/bigint 混合模块常量。
- `sys.modules` 为运行时 dict：名称键映射到模块对象/None，支持成员判断、`len`、局部变量保存。
- `sys.modules[常量名]` 返回真实模块对象，可继续取常量属性或调用模块函数。
- 模块函数值可赋值、转存并静态解析调用。

### 1.4 GC 与循环回收

- 保守式自动栈扫描：栈上等于存活对象指针的字视为根。
- 容器子对象传递标记：list/tuple/set/dict 的键值递归标记至不动点。
- `rt_gc_collect_exact`：跳过保守栈扫描，仅以显式根 + 传递标记判定可达性。
- 双列表互引的合成探针验证不可达环可被回收；子对象挂靠父容器的合成探针验证 GC 后仍可访问。

## 2. 接受为例外的剩余项

1. **精确 live-OBJ 位图**：未实现 per-function 位图与帧链精确扫描。默认仍用保守栈扫描；`rt_gc_collect_exact` 需调用方自行管理根。
2. **运行期动态函数对象**：模块函数值仅支持编译期静态解析（`func:<qualname>`），不支持跨函数传递、返回或运行期多目标动态调用。
3. **循环终结器**：可回收不可达环，但不执行 `__del__`/weakref 等终结语义。

以上三项转入 v0.5/v1.0 重新设计，不在 v0.4 内继续堆补丁。
